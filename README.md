# ИсторияЧиталка 3.0 — Apple Glass Edition

Сайт публикуется GitHub Pages из исходников этого репозитория. ZIP для публикации вручную загружать не требуется.

## Публикация
- В Settings → Pages выберите **GitHub Actions** в разделе Build and deployment.
- Каждое обновление ветки `main` автоматически запускает публикацию.

## Файлы
- `index.html.br` — сжатый HTML; workflow распаковывает его в публикуемый `index.html`.
- `ai-worker.js` — worker локальной языковой модели.
- `tts-worker.js` — worker локальной озвучки.
- `.github/workflows/deploy.yml` — автоматическая сборка и публикация GitHub Pages.

## Локальные модели (без API)
Модели скачиваются при первом использовании и кэшируются браузером. Для первоначальной загрузки требуется интернет; после загрузки модели запускаются в браузере. Большая языковая модель может медленно работать на слабом компьютере.

Документы и заметки хранятся в IndexedDB браузера. Перед переходом между адресами сайта сделайте резервную копию и импортируйте её на новом адресе.
