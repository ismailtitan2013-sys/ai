# ИсторияЧиталка 3.0 — Apple Glass Edition

Проект будет опубликован из архива `HistoryReader3_GitHub.zip` через GitHub Actions. Исходники приложения находятся внутри архива в папке `HistoryReader3/`.

## Публикация сайта

1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите **GitHub Actions**.
3. После загрузки архива workflow распакует проект и опубликует `HistoryReader3/`.

Локальный запуск: распакуйте архив и запустите `start_windows.bat` на Windows при установленном Python.
