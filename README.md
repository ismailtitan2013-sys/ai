# ИсторияЧиталка 3.0 — Reader Studio

Сайт публикуется на GitHub Pages и открывается в Chrome. Его можно установить как отдельное окно через меню браузера.

## Чтение вслух — без AI
- Используется встроенный Web Speech API браузера: `speechSynthesis`.
- Никакая отдельная голосовая модель не скачивается.
- Доступные голоса берутся из Google Chrome и Windows. Если в списке присутствует Google Russian, он автоматически выбирается первым; иначе используется установленный русский системный голос.
- Поддерживаются скорость, высота тона, пауза, продолжение, остановка, чтение отдельных предложений и тест голоса.
- Для чтения нужен установленный русский голос в системе/браузере. Если список пуст, установи русский голосовой пакет Windows в «Параметры → Время и язык → Речь», затем перезапусти Chrome.

## AI — отдельно и по желанию
- Кнопка «AI-рассказ» остаётся отдельной функцией.
- Локальная Qwen LLM не запускается при обычном чтении и не нужна для озвучивания.
- AI требует отдельной загрузки модели около 0,5 ГБ; сама генерация запускается в браузере без inference API.

## Первый запуск
1. Открой https://ismailtitan2013-sys.github.io/ai/ .
2. Добавь PDF или фотографии страниц и дождись распознавания текста.
3. Нажми «Читать». Отдельно загружать голосовую модель не нужно.
4. В настройках выбери нужный голос Chrome/Windows и нажми «Проверить голос».
5. AI запускай только тогда, когда нужен пересказ или объяснение.

## Данные
Документы и заметки хранятся в IndexedDB текущего профиля браузера. Перед сменой браузера/адреса экспортируй резервную копию.

## Файлы проекта
- `index.html.br` — сжатая страница сайта для GitHub Pages.
- `ai-worker.js` — отдельная локальная языковая модель.
- `service-worker.js` — кэш оболочки и установка PWA.
- `scripts/patch_reader.py` — применение браузерной озвучки и проверка исходной страницы.
- `.github/workflows/deploy.yml` — автоматическая проверка и публикация.
