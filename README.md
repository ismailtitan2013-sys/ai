# ИсторияЧиталка 3.0 — Reader Studio

Сайт публикуется GitHub Pages и открывается в Chrome. Его можно установить как отдельное окно через меню браузера.

## Что обновлено
- Светлый нейтральный Liquid Glass-интерфейс без декоративных стикеров.
- Оригинальная страница учебника и извлечённый текст рядом друг с другом.
- Отдельная локальная русская мужская озвучка: «Читать», «Пауза», «Продолжить», «Стоп» и тест голоса.
- Локальная LLM Qwen 0.5B: WebGPU при наличии, стандартный CPU/WASM в остальных случаях.
- PWA-манифест, иконки и кэш интерфейса.

## Первый запуск
1. Открой https://ismailtitan2013-sys.github.io/ai/ .
2. Добавь PDF или фотографии страниц. Для сканов дождись OCR.
3. Нажми «Проверить звук» в настройках. При первом запуске загружается мужская модель VITS около 51 МБ; затем браузер сохраняет её в кэше.
4. Нажми «Загрузить локальный AI» отдельно, когда нужен AI-пересказ. Файлы LLM занимают около 0,5 ГБ и требуют дополнительной оперативной памяти; на слабом компьютере ответы могут быть медленными.

## Голос и ограничения
- Модель VITS имеет два спикера: 0 — женский, 1 — мужской. Это готовый мужской голос, а не специально обученный уникальный молодой тембр.
- Для первого скачивания моделей нужен интернет; сама генерация работает в браузере без inference API.
- Документы и заметки хранятся в IndexedDB конкретного профиля браузера. Перед сменой браузера/адреса экспортируй резервную копию.

## Файлы проекта
- index.html.br — сжатая страница сайта для GitHub Pages.
- ai-worker.js — локальная языковая модель.
- tts-worker.js — локальный мужской голос.
- service-worker.js, manifest.webmanifest, icon-192.png, icon-512.png — офлайн-оболочка и установка PWA.
- .github/workflows/deploy.yml — автоматическая проверка и публикация.
