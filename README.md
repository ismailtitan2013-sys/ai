# ИсторияЧиталка 3.0 — Apple Glass Edition

Сайт публикуется GitHub Pages из исходников в этом репозитории. Архив для публикации вручную загружать не требуется.

## Публикация
- Откройте Settings → Pages.
- В разделе Build and deployment выберите **GitHub Actions**.
- Каждое обновление ветки `main` автоматически запускает публикацию.

## Файлы
- `index.html.br` — сжатый исходный HTML; workflow распаковывает его в сайт как `index.html`.
- `ai-worker.js` — локальный LLM-worker.
- `tts-worker.js` — локальный нейросетевой TTS-worker.
- `HistoryReader3_GitHub.zip` — архивная загрузка, не используется при публикации.

## Локальные модели (без API)
Модели скачиваются при первом использовании и кэшируются браузером. Для первоначальной загрузки требуется интернет; после загрузки модели запускаются в браузере. Большая LLM может медленно работать на слабом компьютере.

Документы и заметки хранятся в IndexedDB браузера. Перед переходом между адресами сайта сделайте резервную копию и импортируйте её на новом адресе.
